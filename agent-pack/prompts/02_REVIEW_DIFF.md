# Prompt 02 — Review the Current Diff

请作为独立代码审查员审查当前工作区的所有改动。不要自动修改代码，先给出审查报告。

重点检查：
- 是否违背仓库已有 `AGENTS.md` / lint 约束。
- 是否发生不必要的重构、依赖膨胀或 UI/engine 层越界依赖。
- 是否存在路径穿越、任意文件读取、符号链接逃逸。
- 是否泄漏数据库密码到日志、项目、URL、前端响应。
- 已保存工程版本是否能通过 UI/API 被覆盖；并发保存是否可能覆盖。
- 失败写入是否可能留下半成品版本。
- 缺失图层是否被删除或仍参与渲染。
- 新发现文件是否被错误地自动加入当前工程。
- 重启、容器重建后配置和工程是否持久化。
- 大 TIFF 是否可能被整体加载到内存。
- Windows/Linux/WSL 路径是否有硬编码或错误假设。
- 测试是否真实覆盖需求，是否有测试被删除或弱化。
- 错误处理是否符合 RustGIS panic/unwrap 规则。

报告分级：
- P0：数据损坏、任意文件访问、秘密泄露、不可变版本可覆盖。
- P1：主要功能错误、工程无法恢复、严重内存风险。
- P2：可用性、兼容性、诊断能力问题。
- P3：风格或低风险改进。

每条问题必须附具体文件、符号/行号、触发条件和建议修复。没有发现问题的类别也要写明“未发现”，不要为了凑数量制造问题。
